# Fullscreen ART (approved Demo03)

The current player keeps its existing fullscreen shell, controls, stripes, modes and one YouTube instance. The SVG disc and tonearm share one coordinate system from approved Demo03. Only the disc group rotates; highlights/pressing marks reveal rotation. The stylus reaches the innermost groove without entering the label. Pause preserves the position, explicit stop lifts/returns, natural end reaches runout for one second then returns. Auto-next starts the next recording instead of delaying its audio. Reduced-motion disables rotation and interpolated movement. Compact-player artwork remains unchanged.

Coverage at this revision: 186 catalog audio appearances + 11 Spinout records = 197 metadata entries (not 197 unique recordings). The reference playback API also uses the same ART; the one existing reference definition is already configured as catalog audio, and alternate reference payloads get their actual current title/artist with unknown release/genre metadata rather than borrowing another rendition's facts. Fresh catalog sources without label metadata still get ART and explicit unknown fields.

Labels distinguish release year and pressing country from production year/country. Existing editorial year is a release year, so production year and country are explicitly unconfirmed throughout. Missing release/pressing/genre values stay unconfirmed. Long title/artist text is measured, wrapped and scaled within bounded label areas; extreme lengths are ellipsized without changing the full accessible player title. No invented metadata, demo tracks, test selector or autoplay mode is shipped.

Tests: fixed675/catalog/GA exact717pages/player regression and mock197labels/needle geometry; new Chromium test iterates all playable labels with real SVG bounds, checks320/390/1200px, rotation, pause, stop, end, reference fallback, reduced motion, compact mode and screenshot artifacts. Browser tests mock YouTube and block third-party network: they do not prove real audio, Japan availability or GA server receipt.
